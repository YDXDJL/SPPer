# HU-087 救生员手表固件

硬件：HU-087（ESP32-S3 N16R8）、SSD1306 128×64 OLED、I²S 扬声器和板载功放。

## 外设参数

| 外设 | HU-087 引脚 |
| --- | --- |
| SSD1306 SDA | GPIO41 |
| SSD1306 SCL | GPIO42 |
| SSD1306 地址 | `0x3C` |
| 扬声器 DOUT | GPIO7 |
| 扬声器 BCLK | GPIO15 |
| 扬声器 LRCK/WS | GPIO16 |
| 功放使能 | GPIO17，高电平开启 |

## 工作流程

1. 每次开机从信道 1～13 搜索主控的 `SPP1 v2` 广播，不使用旧凭据直接入网。
2. 校验广播长度、版本、字段长度和 CRC32，随后连接广播指定的 Wi-Fi。
3. 连接 `ws://<电脑IP>:<端口>/ws/devices`，注册为 `lifeguard_band`。
4. 显示电脑连接状态和泳池安全/溺水泳道，继续使用 5 秒心跳和 15 秒断线检测。
5. 危险时循环播放：三次单次警报音，然后播放对应的“泳道一 / 泳道二 / 两泳道疑似溺水”语音。
6. 收到明确安全快照立即停止播放并关闭功放；危险期间电脑断线则保留最后报警并继续播放。

四段 MP3 位于 `assets/`，由 PlatformIO 直接嵌入应用固件，不需要单独烧录文件系统。

## 构建

```powershell
platformio run
```

构建目标为 `hu-087`：ESP32-S3、16MB Flash、8MB OPI PSRAM、DIO 80MHz。

## COM14 手动下载模式烧录

1. 目标板 `IO0 → GND`。
2. 短接一次目标板 `EN → GND` 后松开 EN，继续保持 IO0 接地。
3. 使用 CH343 的 `COM14`，以 `--before no-reset --after no-reset` 烧录。
4. 成功后断开 IO0，再短接一次 EN 到 GND并松开，启动新程序。

不要连接两块板的 3V3、5V 或 VCC；目标板使用自己的电池供电，两板只需共地。
